# DonutCore (Paper 1.21.4, Java 21)

Build: GitHub Actions automatikusan fordít (Actions fül -> Build -> Artifacts -> DonutCore). Helyben: `gradle build`.

Funkciók: pénz + shard economy (1k/2.5m/1b formátum), /pay /baltop /top, /sell (GUI) /sellhand, /shop, /shardshop,
/ah (aukciósház, 5% adó), /orders (vételi megrendelések), /spawn /rtp /tpa /home, /afk (shard/perc),
/team, /bounty, harc-tag (combat log), oldalsó scoreboard, chat formátum.

Admin: /setspawn, /donutcore setafk|reload|save, /eco give|take|set <játékos> <money|shards> <összeg>
Árak, boltok, limitek: plugins/DonutCore/config.yml
